# AaP3Km Student STEP Quick Start

## Your goal

Use the assigned STEP HTML to add one controlled contribution to your Place investigation and export a new, read-only Traveling Archive descendant. Do not overwrite the parent.

## Before you begin

```text
[ ] I have the assigned STEP HTML release.
[ ] I have the correct parent Traveling Archive.
[ ] I recorded the parent filename/version.
[ ] I verified the MGRS Place Code.
[ ] I retained all source files unchanged.
```

## Work sequence

1. Open the assigned STEP HTML locally.
2. Import the parent archive and required evidence.
3. Confirm Place Code, AOI center point, geometry, and expected counts.
4. Complete the assigned module investigation.
5. Record requests, failures, successful zero results, returned data, and accepted evidence separately.
6. Preserve source values, dates, QA, units, supports, IDs, and citations.
7. Mark unresolved and non-labelable work explicitly.
8. Update the shared session ledger.
9. Export a newly named Traveling Archive descendant and required handoff records.
10. Open the exported archive locally and complete the check-in checklist.

## Never do this

- overwrite the parent archive;
- reuse the parent's filename;
- change the MGRS Place Code;
- treat request JSON as an observation;
- treat returned data as automatically accepted;
- assign field observations or Map Producer classes directly to SSUs without review;
- hide failed requests, zero results, unresolved labels, or excluded records;
- remove source provenance to make the file smaller;
- claim that spectral change proves a cause or land-cover transition.

## Evidence states

```text
NOT_ATTEMPTED
ATTEMPTED_FAILED
SUCCESS_ZERO_RESULTS
CANDIDATE_SOURCE_FOUND
DATA_RETURNED_NOT_REVIEWED
ACCEPTED_FOR_INTERPRETATION
EXCLUDED_WITH_REASON
UNRESOLVED_OPEN_REQUIRED
NOT_APPLICABLE
```

## Submit

Unless the module says otherwise:

1. new Traveling Archive descendant;
2. STEP/session handoff export;
3. module evidence report;
4. archive check-in record;
5. requested supporting artifacts only.

## Final check

```text
[ ] New filename and version
[ ] Parent identity preserved
[ ] Place identity correct
[ ] Geometry and counts reconcile
[ ] Provenance and citations included
[ ] Findings separated from interpretations
[ ] Claim boundaries included
[ ] Unresolved work included
[ ] Accessibility checked
[ ] Files open locally
```
