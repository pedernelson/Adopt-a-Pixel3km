# AaP3Km Traveling Archive Public Contract

**Version:** 2.0

Every public Place-specific artifact must resolve beneath `Earth/{MGRS_PLACE_CODE}/` and retain its full versioned filename.

## Required declarations

- Public-contract conformance
- Style-guide version
- Evidence maturity
- Interface maturity
- Canonical Place path
- Parent artifact filename and hash
- Known deviations

## Required sections

- `#place`
- `#known`
- `#map`
- `#time`
- `#findings`
- `#research`
- `#lineage`

## Required evidence dashboard

Display Geometry, Map User interpretation, Field observations, Map Producer evidence, Temporal evidence, Human Intent, Human Experience, and Interpretation History with explicit state, coverage, and limitation.

## Required claims structure

Separate Accepted findings, Working interpretations, and Claim boundaries. Map-product disagreement alone does not prove physical change.

## Required reSearch queue

Each leading item includes reSearch ID, question, Place support, evidence needed, current state, recommended Process STEP, priority, blocking issue, and expected descendant artifact.

## Required lineage footer

Display full artifact filename, version, parent, hashes, canonical Place path, CRS, schema, evidence count, disclosure state, rights state, release state, and known deviations.
